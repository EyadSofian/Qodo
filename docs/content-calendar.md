# Content Calendar

No production Content Item or calendar view exists.

A future content item must be related to an authorized client, brand and
campaign, and should carry platform, format, pillar, topic, copy, CTA,
language, owners, independent copy/design/video/approval/publishing statuses,
publish time/timezone, approved asset version and published URL.

Drag rescheduling must update the database, validate conflicts and warn about
missing assets/approvals. It must not be implemented as a visual-only calendar.
